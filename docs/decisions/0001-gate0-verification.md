# ADR 0001：先验证基础再冻结技术

状态：提议，2026-10-07。通过I0、后端/媒体同用例、T0、评审及独立验收后才能改为接受；本ADR不宣称实验已运行。

## 决定

主候选Python3.13标准GIL、CrewAI Crews+Flows；Tauri2桌面壳、React工作台、SQLite账本与独立Flow状态、FFmpeg媒体。精确补丁及OS矩阵未冻结。LangGraph仅在独立实验环境对照，两者同模型接口、同Operation账本、同固定用例和质量标准；不构建通用多框架适配层或同时装进生产。

I0已报告真实元数据冲突：完整crewai1.15.23要求mcp~=1.28.1和pydantic>=2.11.9,<2.13，不能将调研快照MCP2.3.0/Pydantic2.13.5直接拼成同环境。先验证官方同版本core拆包是否完整保留必要Crews/Flows/委派/持久化/非阻塞反馈；若不能解决，验证受维护MCP1稳定路线及范围内最高合格Pydantic，核验目标传输/认证/协议。MCP2不是强制需求，不修改上游元数据、不先加第二套运行时；只有必要能力实际失败才另写隔离connector ADR。候选锁可解不等于实验通过。

## Gate0交接实验

| 实验 | 责任角色 | 正向和反向证据 |
| --- | --- | --- |
| G0-01 独立依赖/运行时 | 集成，测试复跑 | Python3.13完整解析、目标wheel/锁文件与实际可执行路径；禁止借其他任务环境或改requires_python强装 |
| G0-02 任务受理/副作用 | 后端，测试注入 | 同主体同键同输入一任务；同键异输入冲突；上游已接收后断线不盲重交；并发/旧租约不可重复提交 |
| G0-03 两库恢复/决策 | 后端与Agent，测试注入 | 文件生成未入库、Step提交未存Flow、未知external_id；非阻塞waiting_user释放槽位，重复/旧版本决策正确处理 |
| G0-04 主动协作对照 | Agent/媒体，后端提供账本 | 只给目标资料→洞察/Brief/3候选→选2→3镜头→改3/表达年轻；角色委派、限次、事实/资产不变；两框架相同边界 |
| G0-05 模式与能力边界 | 后端+Agent，前端显示 | interactive/unattended共用流程；断开HTTP/MCP仍运行；缺中间创作字段不阻断，越预算/白名单/外发正确阻断 |
| G0-06 实际媒体与对齐 | Agent/媒体，集成打包，测试解码 | 打包FFmpeg产出有声10秒中文字幕、9:16/16:9；检查实际音画/旁白/混音/转写与偏移；坏媒体和错时码失败 |
| G0-07 桌面与服务器 | 集成+前端，测试/验收 | 干净Windows/macOS和Linux无桌面实际运行；中文路径、字体、播放/Range、凭证、进程退出/后台、备份恢复 |
| G0-08 包与匹配基线 | 后端+Agent，测试标注 | 无厂商账号/原embedding导出导入重建来源索引；MM03精度与MM05固定正负样本冻结；无合格匹配可拒绝并报告召回 |

模拟可证明状态和故障处理，不证明模型自主创作质量、真实视频生成或跨平台安装。G0-06合成测试不计AC03动画生成通过。DeepSeek真实文本实验已有全部角色合计CNY20授权，可在受控账本内执行相同样本的创作/委派验证；其他收费能力没有新增额度时不调用。真实图片/视频/TTS、跨平台成包与模型效果各有独立证据，文本模型成功不替代它们。

每个实验保存commit、输入/接口哈希、OS/架构、命令/退出码/跳过数、正反输出、Operation/调用数/费用与媒体证据；候选能力、实际通过和未测分别记录。测试开发在真实执行后登记COMMANDS.md，评审不修实现，验收独立复跑。

## 冻结和替换条件

只有满足目标所必需的依赖、协作、非阻塞恢复、费用及打包证据才接受主候选。缺机器/凭证时可继续设计、契约及无依赖验证，不能声称整个Gate0通过或大量扩业务。CrewAI关键实验失败而LangGraph同条件通过，可写新ADR替换；Tauri关键媒体/生命周期失败时用同前端/引擎验证Electron。保持原失败证据，不用Hello World大小或虚构分数作决定。

旧任务固定workflow/schema/provider/render版本；升级需迁移、恢复、回滚验证。当前非测试事实来源是01—11观察快照，发布日期/元数据不算已安装或已兼容。
