# Gate0候选验收标准 v0.1

状态：测试开发提交，等待独立评审及架构冻结。来源为Documents/VideoCreatorSpecification/01—11，哈希见BASELINE.json。标准冻结前不宣布Gate0通过；标准变更保留旧版、失败证据和评审记录。

## 证据等级与判定

`real`为实际生产实现、真实媒体/模型/安装/沙箱接口；`simulated`仅为可重复状态、故障与费用边界测试；`inspection`为代码或文档检查。缺资源、未执行或缺证据记录为`blocked`/`not_run`。不得将skip、Mock、旧素材导入、配置入口或文档声明作为真实功能通过。

每项记录同一代码commit、构建SHA256、标准版本、OS/架构、入口、退出码、测试数/skip数、stdout/stderr及文件哈希。实际费用保留currency及定点amount，未知费用保存unknown；凭证仅句柄，不复制密钥。机器校验只能验证记录完整性，不能代替独立人员看视频、听音频、验签/对账和操作安装。
