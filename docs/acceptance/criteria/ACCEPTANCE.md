# R1/R2候选验收标准 v0.1

测试开发拥有标准和测试；独立评审批准后冻结，独立验收判定阶段完成。生产角色不得改期望、删测试、吞退出码或用Mock替换真实实现。标准当前是候选，所有实现验收项均未通过。

## R1固定门槛

1. 本地免产品注册、官方域名不可达时，实际导入已有素材和上传旁白，1080p的9:16与16:9真实音视频可播放。CPU合成、包体积、时长/内存/GPU按参考机器实测，无未验证保证。
2. 最小输入仅目标与资料。真实模型自行洞察、Brief/主旨、多个剧本候选、分镜及受控路线/制作计划；审核人只确认或指导。至少一条真实口播和一条≥3个新生成镜头的短动画，已有素材/平移静图不能冒充视频模型动画。
3. 一次HTTP/MCP完整制作命令，客户端/会话断开不取消业务。同键同请求返回原production/run；不同输入冲突；并发和进程重启无重复付费重交。预算/外发/资料权利及业务取消由确定性代码执行。
4. 新FeedbackRevision保留原话、主体、目标版本和约束；只改第三镜头，1/2镜头及未变声音资产哈希/调用次数不变；累计已消耗/预留费用和修订轮数不重置。
5. 固定BundleRevision全部请求输出核验后才成功：视频、独立旁白、最终混音、已批准源稿、实际音频转写、SRT/VTT、封面、创作计划、来源/镜头/语义JSONL及RAG文本包；源稿≠转写，prompt≠实际画面描述。音轨映射、方法/精度/工具版本有证据；缺词级能力不假造。
6. 导出校验内容哈希后另实例导入，不依赖厂商账号或原embedding。密钥/Cookie/长期票据/私有日志/本机绝对路径不进包。固定引用版本，Range/ETag、有效期、撤销、跨实例ID、成员项目权限各做正负检查。
7. 来源namespace+文章/主题/事实准确版本关系100%保留；新包不覆盖旧包；撤销/事实失效进入墓碑过滤。至少30选题/60候选人工标注，包含同题不同事实、时效、受众和画面负例；自动返回精确率目标≥90%待Gate0冻结，同时报告召回、top-k、拒答率及样本分布，不全部拒答作弊。纯引用实例搜索及Portal自有索引各实测。
8. Windows EXE、macOS arm64/x64 DMG和Linux x64原生headless包按冻结支持矩阵干净安装、运行、升级/恢复。没对应机器不计通过；未签名验证包与正式签名/公证包分别标记。50镜头UI/API元数据p95≤500ms目标按参考机冻结，06的响应/可访问性目标分别实测。

## R2固定门槛

| 编号 | 行为和真实验收 | 反向检查及边界 |
| --- | --- | --- |
| CM01 | 实际注册/登录/退出、服务会话、账号权限；本地免注册和服务器实例身份独立 | 过期/错误令牌、成员跨项目、官方账号不能成为本地权限源 |
| CM02 | 获授权支付服务真实沙箱订单→签名回调→订阅生效→到期/取消/退款 | 伪造、重放、并发、乱序回调无重复结算或权益；测试模拟故障不计沙箱通过 |
| CM03 | request_id逐笔预留/结算/释放/退款和实例对账 | 断线unknown待核实；重启/重复角色委派不重复扣、反馈不重置预算；定点金额/币种 |
| CM04 | Gateway授权输入目的地、临时媒体TTL与删除证据，结果下载回实例核验并固定交付 | 未授权输入不传；本地工程/媒体长期归实例；上游临时URL非长期引用 |
| CM05 | 官方退出、到期、认证不可达时自有能力/已有素材实际编辑合成导出 | 官方新调用拒绝；已付/已接收结果在冻结交付窗口可查询取回 |
| CM06 | 抖音与小红书各自实际授权/撤销、明确发布、状态查询、作品ID和回执 | 发布与制作分开授权；草稿/受理/成功区分；重复/恢复不得多发；未获测试账号/内容/范围授权不实际发送 |
| CM07 | 三OS安装升级备份恢复，官方服务可复现部署/迁移/回滚 | 错签名、失败迁移、版本不兼容、secret扫描；生产部署需另授权 |
| CM08 | 真实市场/商户、套餐/币种/周期/退款、资源权利、TTL和运营条件记录 | 沙箱≠可正式收费；未决业务参数不能杜撰；缺机器/商户/平台权限/证书必要项阻断 |

CM是补充而非全部R2。FR05/FR10角色/声音/风格一致性增强，FR17音色克隆、数字人口型、高阶时间线及资源包必须冻结具体供应商能力、授权输入、编辑交互、安装兼容和真实样本。缺模型/版权/能力不以设置入口通过。FR18三维/游戏引擎/分布式GPU/公共市场不在本次R1/R2。

## 红→绿和独立验收

保存坏媒体、无关事实/错误时码、越权、超预算、上游受理后断线、文件落盘未入库、入库未成功、伪造/乱序支付、重复发布的实际拒绝/待核实输出；修复或补授权后实际重跑成功，失败证据仍保留。必须项skip=0，冻结覆盖不下降，同一commit与构建产物。模拟故障测试与真实集成样本分别报告，不混合成一个通过百分比。

测试命令和实际运行状态见COMMANDS.md；证据结构检查可用tools/testing/validate_evidence.py，只验证记录一致性和哈希，绝不替代实际播放、安装、模型/沙箱/发布接口的独立核验。
