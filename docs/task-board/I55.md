目标：把“内嵌 Kimi”落实为可供 Backend/Media 消费的精确运行时合同。核定官方 Python SDK、Code CLI 的版本、Python 兼容性、三个目标平台的依赖与完整分发许可；验证可配置工具白名单、关闭默认 Shell/Task/任意 MCP、完整审批事件、有限停止与恢复的真实接口。优先独立可选 Provider 运行时，复用原 native PreparedLaunch，不强装进主环境。源码未能证明的能力明确列缺口，不假设网站生成插件已包含在 SDK 中。

交付：固定版本/许可清单、隔离运行时与跨平台包清单、完整审批/工具事件与恢复接口、失败与退出语义、Backend/Media 下一步签名，以及实际命令终态和普通源副本。自有 stub 仅证明协议，不计 Kimi 服务运行或媒体生成成功。现预算、Owner、Operation 和外发守卫必须先于 prompt 与工具受理，未知任务先查原 task，不因 resume 重交。
