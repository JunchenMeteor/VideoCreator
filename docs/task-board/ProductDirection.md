## 排序原则（承接用户 2026-10-25 确认）

1. 真实成片（本地适用档案）——最小可信内核；
2. 产品内授权替换终端；
3. 模型设置（BYOK + 官方双通道）与费用可见；
4. 发布通道（需真实平台账号）；
5. 生成式画面（HyperFrames 模板）。
