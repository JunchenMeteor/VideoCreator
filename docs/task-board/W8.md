# W8 本地ASR真实转写能力有限验证

永久Agent/媒体角色；仅在I15正式资源Handoff、全部安装/读取句柄终态、资源停写后由统筹恢复。读取固定I15解释器/已安装依赖/模型/许可manifest及ADR0012、现有自身local_asr/asr_worker源码。只写AgentMedia/W8自身过程证据与自有探针/输入输出；本阶段不修改生产源码、主环境、测试/标准或其他角色资源，不触碰T14/ValidationInstance。

目标把仅import/load推进为真实本地中文转写：自有公开许可或本机系统合成的有限语音，固定真实音频字节/hash/来源许可与独立原文，CPU离线子进程真实解码、实际transcribe返回segments/words与时间、实际工具/模型身份、退出/耗时/取消超时边界。至少覆盖原WAV及实际有声MP4音轨解码接缝，明确faster-whisper1.2.1与PyAV19 metadata_errors候选兼容问题；先检查准确接口，再跑有界样本，不吞原异常或生成假transcript。

原文仅参考，不得直接当ASR结果；word estimate不当forced alignment，未测P95/听审不称符合全部精度。模型实际compute_type int8_float32按I15证据保留，不将requested int8写成actual int8。socket阻断/离线模式、独立输出路径、输入音频hash前后、每原handle/实际退出/raw固定；无需新API/key/模型费用或网络下载。不得以另一工具替失败后声称原候选通过。

现有产品driver若不能直接验证允许用自有有限探针定位具体接缝，不能因此声称产品接通；需要生产修复时给出自身文件/接口提案，等T14读取结束、架构准入与统筹另行授权再实施。标准和独立测试由测试角色另行完成。版权分发pending继续保留，Windows样本不外推Mac/Linux。

交付固定输入/实际转写与媒体时间证据、原失败/修订分列、资源/源before-after、正式Handoff。终态后停写/释放读取并FINAL，后续完整Bundle接入与独立验收保持。该局部实测不替自主三生成镜头、完整R1/R2。
