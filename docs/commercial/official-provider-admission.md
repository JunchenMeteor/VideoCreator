## 使用体验与权益

订阅版的必需交付是产品内部可直接生产内容的官方托管服务，不是仅提供模型配置入口。用户登录并取得权益后，在同一工作台提交创作任务、查看进度、审核并接收本地作品包；API/MCP发起的授权自动任务也使用同一能力和成本规则。缺少已准入的生成供应商时，必须明确显示能力未开放，不能将网页插件、模型理解或占位片算作订阅生成能力。

官方服务可以组合文本策划、图像生成、视频生成、配音、转写及本地合成的多个供应商，不要求一个模型完成全部工种。产品Gateway保管商业服务凭证，执行身份、权益、预算预留、任务路由和对账；安装实例保管项目与长期产物，下载校验成功后将视频、音频及文本关联信息纳入本地固定版本作品包。个人BYOK凭证不作为其他订阅用户共享的官方资源。

Gateway的支付、订阅、权益/额度和商业usage账本与安装实例的Operation、资产和作品版本账本独立，以request_id、operation_id及供应商任务ID对应和对账。组合或回退供应商沿同一授权预算与修订限制，未知受理先核实，不能重复生产或把未知费用记为零。实验CNY20不是订阅定价，也不授予商业运营调用额度；商业凭证只由Gateway受控服务持有，不进入作品包、Flow或本地导出。

退出登录、订阅到期或官方服务失效不锁本地项目、BYOK、自有素材合成及既有作品读取/导出。已受理官方任务的查询、费用核实与结果取回窗口应在供应商准入时明确，不能因前台断线重置账本或悄悄删除结果。Gateway/供应商只持任务必需的临时数据，TTL、删除与取回条件明确；长期工程、视频、音频及语义文本默认归安装实例。

用户在本产品内完成授权创作，模型/媒体服务通过厂商允许的API、MCP或等价服务端接口受理、查询、下载并对账；无需安装或打开供应商App、复制代码或手搬文件。供应商官网内部插件可生成，不自动等于产品后台可调用。

已存在source=owned_remote/owned_local/official三类路线。BYOK/本地属于用户安装实例的独立能力，免本产品账号；official由本产品Gateway管理服务凭证与官方权益。用户私人官网会员、Code订阅API、开放平台API与本产品官方资源分别核验密钥范围、费用和调用权，不能借私人密钥或未授权cookie/客户端伪装充当商业官方后台。

## 每项能力必须有的准入证据

| 项 | 必须核验 |
| --- | --- |
| 允许的接口 | 官方来源、接口/协议版本、认证和具体生成工具；MCP连接外部工具的能力不证明生成插件可对外调用 |
| 实际生产 | 该账号/权益真实受理所需文本/图片/视频/声音输入、返回可验证产物；声明规格、参考/角色/克隆/口型能力与限制 |
| 持久任务 | 稳定任务/请求ID、查询/结果下载/过期、取消语义；断线与不明受理能核实，不盲目重交或承诺所有服务exactly-once |
| 商业调用权 | 明确后台调用/提供本产品服务及生成产物使用/分发条件、声音/素材授权；套餐覆盖不凭同一品牌或key外推 |
| 费用或额度 | 受理前成本边界/额度预留，真实usage、供应商任务/订单/额度记录与request_id对账；未知不标0，订阅覆盖也留可核验依据 |
| 稳定与边界 | 超时、限流、权限失效、并发、重启、结果损坏/超限及撤销；有限回退保持原预算/外发与能力许可 |
| 数据目的地 | 只发授权任务必需输入；官方/供应商临时媒体TTL、日志最小化、删除证明及已接收/已付款结果取回窗口明确 |
| 实例落盘 | 校验下载并固定Asset/Bundle版本，项目和产物长期归安装实例；退出/到期不锁自有能力、已有素材合成、读取和导出 |

能力逐项准入，文本或图片理解通过不授予视频生成。公开契约需记录准入证据/范围/版本，而不是只凭CapabilityRoute.verified=true或页面按钮获得official商业资格。后端维护唯一公开Schema，Agent/媒体实现Provider，集成纳管资源/SDK，测试/评审/验收按各自职责取证；本文件不是供应商或商业上线批准书。

## Kimi和本地代码渲染的当前边界

官方帮助的K3创意插件图像/视频/音频生成已有公开证据；本产品可调用的公开API/MCP、该用户权益与价格未证实。一次kimi-k2.6开放平台chat图片理解401只说明该端点未认证通过，不能外推官网会员不能生成或所有key失效；原路线停止，不切端点盲试。当前Kimi不满足本产品official生成Provider准入。

模型写代码并经本产品受控工具实际渲染，可以形成可验真的程序化创作；颜色块/推近/测试信号只证明渲染链，不自动满足AC03真实自有服务与三生成动画镜头。官网插件生成、模型原生输出和本地程序化合成分别记录路线和实际镜头证据，按原AC03评审验收，不静默替换标准或把测试片称成品。
